LANCEMENT
─────────
Double-cliquez sur :  start.bat
Puis ouvrez :         http://localhost:3000

STRUCTURE DES DONNÉES
──────────────────────
data/
  2026-05.json   ← mai 2026
  2026-06.json   ← juin 2026
  ...

Chaque mois a son propre fichier JSON.
Le sélecteur dans le menu gauche permet de
naviguer entre les mois.

DÉBUT DE MOIS
─────────────
Double-cliquez sur :  nouveau-mois.bat
Il crée automatiquement le fichier du mois suivant.

CHANGER DE PC
─────────────
Copiez le dossier entier. Vos données sont dans data/.
Node.js doit être installé sur le nouveau PC.
